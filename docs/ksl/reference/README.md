# KSL Reference

Three document kinds: [project](project.md), [module](module.md), [spec](spec.md).

Each page uses the same **Imbrication** table:

| Block | Chain | Description |
|-------|-------|-------------|
| `strategies { … }` | spec → [strategies](strategies.md) → [strategy](strategy.md) | where to read arguments |

- **Block** — KSL syntax you write.
- **Chain** — path from parent to child (`spec → strategies → strategy`).
- **Description** — internal link to the page that documents that level.

Start from [spec](spec.md) for T2 blocks, or [project](project.md) for stack/repo.
