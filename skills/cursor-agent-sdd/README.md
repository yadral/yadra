# Cursor Agent — skill SDD Yadra

Copie ce skill dans Cursor pour que l’agent comprenne Yadra (KSL, T1/T2) sans dériver.

```bash
mkdir -p ~/.cursor/skills/yadra
cp skills/cursor-agent-sdd/SKILL.md ~/.cursor/skills/yadra/SKILL.md
```
